Supervisor Agent (Planner)

Welcome to NextRole. I am the Supervisor Agent — orchestrating your multi-agent career prep pipeline.

Multi-agent architecture:

  • Supervisor Planner: Analyses candidate CV + target JD, builds an execution plan, and maps skill gaps.
  • research-agent: Live web intelligence via Tavily → Evidence DB (company background, hiring trends, salary data).
  • resume-agent: Tailors resume against target requirements → RenderCV YAML spec + Markdown preview.
  • interview-agent: Formulates STAR stories, technical responses, and round strategies.
  • Critic Agents: QA verdicts (score 0-100). FAIL → Re-plan, PASS → Judge.
  • Judge: Synthesizes approved outputs into the final Day-of Battlecard.
  • User Approval → Career Memory: Persists verified artifacts to local memory.

To begin: Upload your CV under Workspace, then search opportunities or paste a target JD URL.
